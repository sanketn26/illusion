# Philosophy

## Why this project exists

Most people meet physics through formulas, lectures, or finished diagrams. `illusion` focuses on the missing layer: watching a system evolve until the behavior becomes intuitive.

Each topic is treated as a system with:

- state
- rules
- constraints
- observables
- feedback
- emergence
- failure of intuition

The core question for every simulation is:

> What does the visual system reveal that words alone cannot?

## Tone

The tone for the project should stay:

- precise
- visual
- humble
- code-first

## Episode shape

Every episode should include four parts:

1. **The illusion**
2. **The model**
3. **The reveal**
4. **Where the simulation lies**

That last section matters. A simulation is a controlled lens, not a proof.

## Audience

This project is for:

- software engineers curious about physics
- students who need visual intuition
- self-learners who like first-principles explanations
- builders who want to see equations become simulations
- viewers who enjoy channels like 3Blue1Brown, PBS Space Time, Veritasium, and Primer
