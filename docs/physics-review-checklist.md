# Physics Review Checklist

## Before releasing any episode

- [ ] Is the main illusion clear?
- [ ] Is the simulation small enough to understand?
- [ ] Is the governing equation or rule visible?
- [ ] Does the visual reveal something words alone do not?
- [ ] Did I explain where the simulation is wrong or incomplete?
- [ ] Did I avoid claiming that the toy model proves the full theory?
- [ ] Is the code readable?
- [ ] Can the scene be rendered again from scratch?
- [ ] Is there a short version for social media?
- [ ] Is there a GitHub note for learners?

## Review framing

- [ ] Are the simplifications explicit?
- [ ] Are the failure modes or misleading intuitions called out?
- [ ] Is the model scoped tightly enough for the episode goal?
- [ ] Is the output visual doing work that narration alone cannot do?
